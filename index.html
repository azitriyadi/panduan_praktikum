🚀 6. Tugas Mandiri: Kalkulator Konsol Bermenu & Modul Operasi
operasi3.py & kalkulator.py

Tugas Mandiri: Terdiri dari 2 berkas, yaitu modul fungsi logika & matematika mandiri (operasi3.py) dan program utama konsol bermenu interaktif (kalkulator.py) yang mengimpor modul tersebut serta mengimplementasikan perulangan while True, validasi input .isdigit(), dan nested loop matriks.

📦 Berkas 1: Modul Logika & Fungsi Matematika (operasi3.py)
Modul Fungsi

📋 Spesifikasi Fungsi Mandiri (operasi3.py):

  1. tambah(a, b): Mengembalikan hasil penjumlahan $a + b$.
  2. kurang(a, b): Mengembalikan hasil pengurangan $a - b$.
  3. kali(a, b): Mengembalikan hasil perkalian $a \times b$.
  4. bagi(a, b): Mengembalikan hasil pembagian $a / b$. Menangani pencegahan error saat pembagi bernilai nol ("Error: Pembagi tidak boleh bernilai nol!").
  5. cek_ganjil_genap(angka): Memeriksa sifat bilangan ganjil/genap menggunakan operator modulus (%), mengembalikan "GENAP" atau "GANJIL".
  6. hitung_deret_aritmatika(awal, beda, n): Menghitung total akumulasi deret menggunakan perulangan for.
💻 Berkas 2: Program Utama Konsol Bermenu (kalkulator.py)
Program Utama

📋 Fitur & Logika Menu (kalkulator.py):

  1. Menu 1 (Operasi Aritmatika Dasar): Sub-menu A (+), B (-), C (*), D (/), validasi input menggunakan .isdigit(), memanggil fungsi dari modul operasi3.
  2. Menu 2 (Cek Sifat Bilangan): Meminta input angka positif dan memanggil operasi3.cek_ganjil_genap(angka).
  3. Menu 3 (Hitung Deret Aritmatika): Meminta input suku awal, beda, dan banyak suku ($n$), validasi while n <= 0, memanggil operasi3.hitung_deret_aritmatika().
  4. Menu 4 (Cetak Tabel Perkalian Matriks): Mencetak matriks perkalian 1–3 menggunakan nested loop (loop baris dan kolom).
  5. Menu 5 (Keluar): Menampilkan pesan terima kasih dan menghentikan perulangan dengan break.
📤 7. Panduan Pengumpulan Tugas ke GitHub
Git Workflow

Lakukan langkah-langkah di bawah ini secara disiplin untuk mengumpulkan hasil tugas ke GitHub organisasi.

1️⃣ Fork Repositori Kelompok
Buka repositori organisasi di GitHub dan klik tombol Fork ke akun pribadi kalian.
2️⃣ Clone ke Komputer Lokal
Buka terminal lalu ketik perintah clone:
git clone https://github.com/USERNAME-KAMU/tugas-minggu-2.git
cd tugas-minggu-2
3️⃣ Buat Folder Format nama-NPM & Berkas README.md
Buat direktori kerja pribadi dan buat berkas README.md dengan format wajib:
mkdir ahmad-2610001
cd ahmad-2610001
📝 Format Isi README.md Mahasiswa: 
# Tugas Minggu 2 - Pelatihan Python Lanjutan & GitHub

- **Nama**     : [Nama Lengkap]
- **NPM**      : [NPM Mahasiswa]
- **Kelompok** : [Nomor Kelompok]

4️⃣ Minimal 3 Kali Commit Bertahap
Disiplin riwayat commit bertahap (*atomic commits*):
git add praktikum_*.py
git commit -m "feat: menyelesaikan modul latihan praktikum 1 sampai 4"

git add operasi3.py kalkulator.py
git commit -m "feat: menyelesaikan modul kalkulator dan program menu terpadu"

git add README.md .gitignore
git commit -m "docs: melengkapi dokumentasi dan konfigurasi gitignore"
5️⃣ Push dan Ajukan Pull Request
Unggah perubahan ke GitHub dan buka Pull Request ke repositori induk:
git push origin main
